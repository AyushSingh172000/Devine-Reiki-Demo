2. File Directory Architecture

In the InfinityFree File Manager (filemanager.ai), the web root folder is always htdocs/.

Important Root Placement Rule:
All files (index.php, contact.php, assets/, config/, includes/, etc.) must reside directly inside htdocs/, NOT nested inside a subfolder like htdocs/DemoWebsite/.

4. Dynamic URL & Reverse-Proxy Resolution (config/constants.php)

InfinityFree and Cloudflare utilize edge reverse-proxies to terminate SSL/TLS. config/constants.php dynamically detects whether traffic is coming through HTTP_X_FORWARDED_PROTO so that assets never face mixed-content security blocks:

// Dynamic Base URL definition
if (!defined('BASE_URL')) {
    if (isset($_SERVER['HTTP_HOST']) && isset($_SERVER['SCRIPT_NAME'])) {
        $isHttps = (isset($_SERVER['HTTPS']) && $_SERVER['HTTPS'] === 'on') 
            || (isset($_SERVER['HTTP_X_FORWARDED_PROTO']) && $_SERVER['HTTP_X_FORWARDED_PROTO'] === 'https');
        $scheme = $isHttps ? 'https' : 'http';
        $host = $_SERVER['HTTP_HOST'];
        $dir = str_replace('\\', '/', dirname($_SERVER['SCRIPT_NAME']));
        $baseDir = rtrim($dir, '/') . '/';
        define('BASE_URL', "{$scheme}://{$host}{$baseDir}");
    } else {
        define('BASE_URL', 'http://localhost/reikibliss/');
    }
}

5. Smart Dual-Environment Database Configuration (config/db.php)

To ensure you can continue developing locally on XAMPP while simultaneously running live on InfinityFree without breaking either environment, config/db.php uses dynamic host-detection:

<?php
// Database configuration and PDO connection

// Check if running on Local XAMPP
$hostHeader = $_SERVER['HTTP_HOST'] ?? ($_SERVER['SERVER_NAME'] ?? '');
$isLocal = (strpos($hostHeader, 'localhost') !== false || strpos($hostHeader, '127.0.0.1') !== false);

if ($isLocal) {
    // Localhost XAMPP Environment
    $host = 'localhost';
    $port = 3306;
    $dbname = 'reiki_website';
    $username = 'root';
    $password = '';
} else {
    // InfinityFree Cloud Production Environment
    $host = 'sql206.infinityfree.com';
    $port = 3306;
    $dbname = 'if0_42861215_reikibliss';
    $username = 'if0_42861215';
    $password = 'Ayush171998';
}

$charset = 'utf8mb4';
$dsn = "mysql:host={$host};port={$port};dbname={$dbname};charset={$charset}";

$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, $username, $password, $options);
    $pdo->exec("SET NAMES utf8mb4");
} catch (\PDOException $e) {
    die("Database Connection Failed: " . $e->getMessage());
}

return $pdo;

6. Common Issues & Solutions

Issue / Error Root Cause Exact Solution
SQLSTATE[HY000] [2002] No such file or directory PHP tried connecting to 'localhost' on InfinityFree, attempting to use a local Unix socket instead of TCP network host. Set $host = 'sql206.infinityfree.com' and explicitly specify port=3306 in the PDO DSN string.
Website shows Index of / directory listing Files were uploaded inside a nested subfolder (e.g. htdocs/DemoWebsite/) instead of directly in htdocs/. In File Manager, select all files inside DemoWebsite and move them directly to the parent htdocs/ directory.
CSS or Images not loading Hardcoded BASE_URL pointing to localhost. Ensure config/constants.php uses dynamic $_SERVER['HTTP_HOST'] resolution (already implemented).
Free SSL Certificate (HTTPS) InfinityFree subdomains start on HTTP by default. In the InfinityFree dashboard, go to Free SSL Certificates, click New SSL Certificate, choose Let's Encrypt / ZeroSSL, and follow the 1-click install.
